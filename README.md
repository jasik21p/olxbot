# 🚗 OLX.uz Car Monitor Telegram Bot

Высокоскоростной Telegram-бот для мониторинга свежих объявлений легковых автомобилей на сайте **OLX.uz** в реальном времени.

## ✨ Основные возможности

1. **⚡️ Мониторинг в реальном времени**:
   - Динамическая настройка частоты проверки прямо из Telegram (от 0.5 до 10+ секунд, по умолчанию 1.0 сек).
   - Фильтрация старых и ТОП-объявлений: бот отправляет **исключительно новые объявления**, созданные после старта бота. Старые объявления, искусственно поднятые или закреплённые в ТОПе, отсекаются.
   - База данных SQLite (`seen_ads`) запоминает историю, исключая дубликаты.

2. **👑 Иерархия Администраторов**:
   - **Главный Администратор (`ID: 5905608906`)**:
     - Только он может назначать новых администраторов.
     - Только он может лишать прав администратора у других пользователей.
     - Доступ к разделу «👥 Управление администраторами».
   - **Обычные Администраторы**:
     - Назначаются Главным Администратором по Telegram ID.
     - Могут настраивать частоту обновлений в реальном времени.
     - Могут менять мастер-пароль бота.
     - Могут просматривать статистику бота.
   - **Все Администраторы имеют постоянный доступ к боту без ввода пароля** (пароли требуются только сторонним пользователям).

3. **📍 Фильтры по регионам и городам Узбекистана**:
   - Быстрый выбор любого из 14 регионов Узбекистана (Ташкент, Самарканд, Андижан, Бухара, Фергана и др.) или «Вся страна».
   - Возможность ручного ввода конкретного города или района (например: *Чиланзар, Ургенч, Ангрен*).

4. **📸 Детальные уведомления**:
   - Фотоальбом (до 8 фото).
   - Цена в USD ($) и UZS (сум) по курсу OLX.
   - Пробег (км) и вид топлива (Бензин, Газ/Бензин, Дизель, Электро, Гибрид).
   - Год выпуска, модель, локация, описание.
   - Контакты продавца (через OLX Phone API + умное сканирование описания).
   - Прямая ссылка и кнопка перехода на OLX.uz.

5. **🔒 Защита паролем и сессии**:
   - Обычные пользователи получают доступ только после ввода пароля.
   - При смене пароля любым администратором все обычные пользователи мгновенно разлогиниваются (все администраторы сохраняют доступ).
   - Защита от дублирующих процессов (Single-Instance Lock): исключает конфликты нескольких запущенных процессов.

---

## 🚀 Запуск на Windows

Запустите файл:
```bat
start_bot.bat
```
